**Note on Module 6:** Hepworth has no dedicated culturally-competent-practice chapter, so this module draws on the school's own Afrocentric Perspective materials instead — per the BSW Program's Afrocentric Perspective curriculum crosswalk, 403 is specifically assigned 3 of the Perspective's 10 concepts:

- **Matrix Roles** — personification of effective professional strategies for eliminating human oppression and enhancing human potential
- **Intuitive** — recognizing and accepting the importance of emotion in determining what is real
- **Humanistic Values** — values that place priority on eliminating human oppression and enhancing human potential, valuing human values over all values

Applied through the DIASPORA Model (D-I-A-S-P-O-R-A) as the structuring framework for the rotation's case analysis, using the school's existing "Afrocentric Perspective Case Study" assignment format (small-group case study + DIASPORA Model + Flipgrid video) rather than a generic hypothetical issue. **Confidentiality note:** the case must be de-identified and composite — no real client names, identifying details, or agency-identifying information — consistent with rotation-site confidentiality obligations.

**Note on Module 4:** the "First Client Case" is the school's existing semester-long small-group assignment (weekly case staffing → genogram, ecomap, treatment plan), used here as Phase 1's content rather than the originally drafted individual Applied Intake Summary/SMART Goal Plan. The Phase 1 Benchmark Checkpoint is scored on both the shared group case materials and each student's individual weekly reflections, so certification of readiness to advance to Phase 2 stays tied to the individual student even though the case materials are produced collaboratively.
