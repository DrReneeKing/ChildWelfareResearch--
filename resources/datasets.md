# Datasets

Approved datasets or authoritative links students should use for this course's data-science-based assignments. A dataset here is a prerequisite for building the assignment in Module 04, not an afterthought — no entry, no assignment yet. If a dataset is restricted-use, the terms-of-use/data-sharing agreement is part of that same prerequisite.

- [x] **AFCARS Foster Care AB File, FY2023** (Dataset #303) — National Data Archive on Child Abuse and Neglect (NDACAN), Cornell/Duke, on behalf of the Children's Bureau, ACF — used in Module 8 / capstone ("Foster Care Data Stories by the Numbers"). Restricted-use: **NDACAN Terms of Use Agreement on file** (signed 2025-09-13; purpose: undergraduate Child Welfare course capstone data-science project). Delivery via NDACAN secure channel only; no redistribution; students may not attempt to identify research subjects; secure disposal required at agreement termination.
- [x] **NCANDS Child File codebook** — federal child-maltreatment reporting data (Children's Bureau); codebook staged locally for reference/instruction (`Dataset/ncands_child_file_codebook.pdf`). Confirm whether the underlying NCANDS microdata itself is in hand or codebook-only before building an assignment against it — a separate NDACAN Terms of Use Agreement is required for the actual case-level file.
- [x] **AFCARS Foster Care codebook** — companion codebook to the AB File above (`Dataset/afcars-foster-care-file-codebook.pdf`); used for variable reference during Modules 2–7.
- [x] **GCBS Comprehensive Dataset v2.1 (Instructor)** — (`Dataset/GCBS_FULL_Comprehensive_Dataset_v2_1_Instructor.pdf` + `.xlsx`) — used for early-module practice (Modules 3–6: tool orientation, R basics, wrangling, analysis) before students work with the restricted AFCARS data directly.
- [ ] Public/aggregate **Child Maltreatment 2023** (NCANDS annual statistical report, HHS/ACF/Children's Bureau, 34th ed.) — not case-level, no data-sharing agreement needed; useful as a Module 1–2 reading/context source (national and state-level statistics) rather than a hands-on dataset.

## Notes

- The AFCARS/NCANDS restricted-use files are why Modules 2–7's hands-on practice should lean on the GCBS dataset first, saving the actual federal case-level data for the Module 8 capstone where the terms-of-use purpose statement (already on file) specifically covers it.
- Any new restricted-use dataset added here needs its own signed Terms of Use Agreement noted alongside it — don't assume the existing AFCARS agreement covers a different dataset or a different stated purpose.
